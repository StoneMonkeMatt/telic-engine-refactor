## Primary ensemble recovery result

For matched pair `j`, feedback state `Z` and rotation `r`:

\[
\Delta_{j,Z}^{(r)}
=
Y_j(real,Z)-Y_j(sham_r,Z).
\]

The sham-choice nuisance variable was averaged inside each pair:

\[
\overline\Delta_{j,Z}
=
\frac1{14}\sum_{r=1}^{14}\Delta_{j,Z}^{(r)}.
\]

Under active repair feedback:

\[
\overline\Delta_{Z=1}
=-0.01576450893.
\]

Matched-pair 95% interval:

\[
[-0.03384545473,\ 0.00231643687].
\]

The interval crosses zero. The preregistered positive true-history hypothesis was not supported.

All fourteen rotation-specific point estimates were negative:

- minimum: **-0.03173828125**;
- maximum: **-0.0078125**;
- negative point estimates: **14/14**;
- individual intervals entirely below zero: **1/14**;
- individual intervals crossing zero: **13/14**.

Rotation 7 was exactly the median-ranked point estimate, seventh most negative of fourteen. Rotation 13 was the only individual sham comparison whose interval excluded zero.

The correct primary conclusion is:

\[
\boxed{
\text{true chronology did not establish a repair advantage over the complete cyclic-sham ensemble}
}
\]

The uniformly negative point estimates are a strong directional pattern, but the eight-pair ensemble interval still crosses zero. A general true-history disadvantage is therefore not established either.

Carrier-003B establishes:

\[

\text{temporal order is a robust causal input across all cyclic sham rotations}
}
