Date: 17 July 2026  
Status: preregistered before outcome execution

Crown line: **The same memories can carry different information when their order changes.**

## Question

Does the true chronological ordering of the retained EMA history improve structural repair relative to a sham history containing the exact same values, duration, total exposure, and terminal checkpoint anchor?

Carrier-002C established that retained macro-history can change reachable decisions. Carrier-003 tests whether the order of that history contains useful control information rather than merely perturbing the system.

## Frozen substrate

Carrier-003 inherits without refitting:

- the frozen V2.2 matched panel;
- 8 matched checkpoint pairs;
- 16 symbolic microstates;
- 512 exact two-bridge wounds;
- the Carrier-002 state capsules;
- the Carrier-002C reachable continuity carrier;
- EMA coefficient `alpha = 0.2`;
- continuity coefficient `w_D = 0.5`;
- feedback strength `kappa = 0.25`;
- identical proposal, tie-breaking, admission, lesion, and branch random streams.

No coefficient sweep, emergence declaration gate, forced mutation, or feedback-strength change is permitted.

## Timing schedules

For each capsule, form a 16-value historical EMA schedule:

1. take the final 16 values of `boundedDualityHistory`;
2. where fewer than 16 values exist, left-pad with the earliest available value;
3. preserve the terminal value exactly equal to the capsule checkpoint `dEma`.

### Real arm

The 16 values are exposed in their true chronological order.

### Equal-distribution sham arm

The first 15 positions are rotated left by exactly 7 positions. The terminal checkpoint value remains fixed in position 16.

Therefore real and sham preserve:

- the exact same value multiset;
- the same schedule length;
- one exposure per schedule position;
- the same total exposure;
- the same terminal anchor;
- the same microstate, wound, targets, feedback, capsule identity, and random stream.

Only temporal alignment changes.

The timing schedule is consulted for the first 16 decision steps. After step 16, each branch continues with the endogenous Carrier-002C capsule update generated by its own accepted trajectory.

## Neutrality gate

Before timing is activated, both real and sham schedule payloads must reproduce the corresponding active Carrier-002C projection hash exactly.

Any mismatch aborts the experiment before interpretation.

- Decision or trajectory differences establish that temporal ordering is causally influential under this replay intervention.
- A positive pair-level interval for `Delta_Z=1` is required to establish that true ordering improves repair relative to sham.
- A crossing-zero interval leaves useful timing control unestablished even if decisions differ.
- Carrier-004 held-out generalisation is admissible only after the true ordered history clears the preregistered directional recovery test.
