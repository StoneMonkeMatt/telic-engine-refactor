```typescript
export function scoreNote(params: {
  scores:     RetrievalScores;
  confidence: ConfidenceLevel;
  governance: NoteGovernance;
  searchMode: SearchMode;
}): number {
  const { scores, confidence, governance, searchMode } = params;

  // Average the four field scores — each field is 0–1
  const baseScore = clamp(
    (scores.titleScore + scores.keywordScore + scores.symbolScore + scores.domainScore) / 4,
  );

  const weighted = baseScore * CONFIDENCE_WEIGHTS[confidence];

  const goldenAdjusted =
    governance.goldenKey === "current"
      ? weighted + RETRIEVAL_RULES.goldenKeyBonus
      : weighted;

  const supersededAdjusted =
    governance.goldenKey === "superseded" && searchMode === "normal"
      ? goldenAdjusted + RETRIEVAL_RULES.normalSearchSupersededPenalty
      : goldenAdjusted;

  return clamp(supersededAdjusted, 0, RETRIEVAL_RULES.maxScoreCap);
}

export const RETRIEVAL_RULES = {
  goldenKeyBonus:                 0.25,
  normalSearchSupersededPenalty: -0.15,
  lineageSearchSupersededPenalty: 0.0,
  maxScoreCap:                    1.0,
} as const;
```

V9 bug-fix theorem, verbatim source comment: "V9 bug fixed: fields are AVERAGED (each 0–1), not summed then clamped. Summing four 0–1 fields then clamping to 1.0 destroyed differentiation — any note with >1 field matching scored 1.0 before the confidence weight."

#### 31.6.14 Exact frontier law, temperature, and kernel boundary

The flat generator produces one randomly instantiated candidate for each available operator type. The stratified generator produces one candidate for each available role-specific branch. It does not enumerate every possible insertion, deletion, merge, or swap. Thus the frontier itself is random:

\[

\[

\Pr(F\mid s)
\mathbf 1\!\left[
\operatorname{sequence}(h_{\mathrm{seed},t}(M(F)))=s'
\right]
A_F(s,s')
\]

for \(s'\neq s\), where \(h_{\mathrm{seed},t}\) is the stable-sort seeded-index selector. The self-loop probability contains rejected candidates and selected identity records.

A simple factor

\[

is not the recovered runtime law. Tie selection is not random-uniform for a fixed run, duplicate candidate records are not removed, and their multiplicity changes the sorted pool and seeded index.

##### Exact algebraic properties

On the active known-symbol library, the audit harness found every output inside the same library, including every registered bridge symbol. V3 therefore types the current known-symbol restriction as a closed binary operation

\[
\star_2:\mathcal G\times\mathcal G\to\mathcal G.

The exact library cardinality remains outside this closure because earlier source and documentary counts conflict. Closure on arbitrary input strings does not hold: an unknown string may be returned unchanged.

The operator is idempotent:

\[
\boxed{a\star_2 a=a}
\]

for every known glyph and, through the left-projection branch, every repeated unknown string.

It is not commutative. Equal-weight ties return the left operand. A recovered active-library witness is

\[
\text{⚓}\star_2\text{🐋}=\text{⚓},
\qquad
\text{🐋}\star_2\text{⚓}=\text{🐋}.
\]

The bridge lookup itself is symmetric in its two domain arguments, but the whole operator is not symmetric because of this tie rule and the unknown-symbol projection.

It is also not associative. A source-executed witness is

\[
(\varnothing\star_2\bot)\star_2\text{📍}=\vdash,
\]

while

\[
\varnothing\star_2(\bot\star_2\text{📍})=\text{📍}.
\]

The first association activates a Logic--Mathematics bridge and injects the weight-100 glyph \(\vdash\); the second first selects the higher-weight waypoint and never encounters that bridge. Hence

\[
\boxed{
(a\star b)\star c\ne a\star(b\star c)
\quad\text{in general}.
}
\]

The sampled associativity-failure and rotation percentages returned by the worker are retained only as empirical receipts. The counterexample, not the percentages, closes the mathematical property.

No two-sided identity or strictly absorbing element was found in the loaded current library. Candle and Void are instead **conditionally absorbing override symbols**:

\[
x\star_2 C=C\star_2 x=C,
\qquad
x\star_2 V=V\star_2 x=V

for ordinary glyphs \(x\notin\{C,V\}\), but their mutual product is \(O\). Their current table is

\[
\begin{array}{c|cc}
\star_2&C&V\\ \hline
C&C&O\\
V&O&V
\end{array}
\]

In \(G_1\), Candle was strictly absorbing over the known-symbol library because the exceptional Candle--Void product also returned Candle.

The operation is not a lattice join or meet. Idempotence alone is insufficient; commutativity and associativity both fail, and no executable partial order supplies the missing lattice structure.

##### Pair-halving compression recurrence

The full compression routine is a separate balanced-tree process. For

\[
s^{(t)}=(s^{(t)}_1,\ldots,s^{(t)}_{n_t}),
\]

it computes non-overlapping pairs from index zero:

\[
s^{(t+1)}_j
=
 s^{(t)}_{2j-1}\star s^{(t)}_{2j},
\]

and copies the final unpaired glyph unchanged when \(n_t\) is odd. Therefore

\[
\boxed{
n_{t+1}=\left\lceil\frac{n_t}{2}\right\rceil.
}
\]

Absent an earlier terminal stop and with a sufficient step budget, the structural depth to a singleton is

\[
\boxed{
\left\lceil\log_2 n_0\right\rceil.
}
\]

The pairing offset is always zero. Consequently the result depends on input order, odd-tail position, and the balanced parenthesisation tree. It is not a function of the symbol multiset alone.

The current stopping rules are:

1. stop before a layer when its length is at most one;
2. compute `next`, then test exact array equality before appending it;
3. append the next layer;
4. stop when that layer is uniformly Candle or uniformly Void;
5. otherwise stop when the hardcoded step budget is exhausted.

The equality-based stability check is unreachable under the current recurrence. Whenever the loop enters, \(n_t\ge2\), so

\[
\left\lceil\frac{n_t}{2}\right\rceil<n_t.
\]

The two arrays have different lengths and cannot be equal. V3 therefore records this check as dead under the present pair-halving implementation.

The uniform-Candle and uniform-Void checks can stop above length one. For example,

\[
(C,C,C,C,C,C,C,C)
\longmapsto
(C,C,C,C),
\]

and the process stops at that four-symbol layer because it is already a named terminal state. Every singleton is nevertheless a code fixed point because the loop never executes. Every glyph is also an operator fixed point under \(\star_2\), but only Candle- and Void-uniform layers receive the named terminal classification.
