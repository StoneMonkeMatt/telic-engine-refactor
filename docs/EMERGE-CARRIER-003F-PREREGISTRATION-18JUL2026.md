## 3. Active native-boundary formula

Carrier-003C remains the base score. Carrier-003F adds exactly one signed event term:

\[
R_t^{true}(c)
=
R_t^{003C}(c)+w_b b_t(c).
\]

The coefficient is fixed once at:

\[
\boxed{w_b=0.01}.
\]

Because a valid fixed-state frontier cannot contain both an entry and an exit, the maximum pairwise score differential introduced by the event formula is \(0.01\), not \(0.02\). This is a one-percentage-point score perturbation and is below the maximum absolute signed-slope adjustment observed on the same frozen Carrier-003C substrate:

\[

The weight was selected from the already-dark score scale before any active boundary outcome execution. It will not be swept, adapted, subgroup-selected or changed if the confirmatory result is null or negative.

## 4. Geometry-safe equal-exposure sham family

Rotating the EMA history is prohibited for Carrier-003F because it can create boundary labels inconsistent with the realized current state. The sham acts only on candidate ownership of the already-valid event labels.

For frontier \(f\), canonically order its four candidates by the stable receipt:

\[
\rho_f(c)=\operatorname{SHA256}(type(c),sequence(c)).
\]

Let the valid native event vector in that order be:

\[
B_f=(b_f(c_1),b_f(c_2),b_f(c_3),b_f(c_4)).
\]

For sham schedule \(r\in\{1,2,\ldots,14\}\), define a deterministic permutation \(\pi_{r,f}\) by sorting candidate indices on:

\[
q_{r,f}(i)
=
\operatorname{SHA256}(
\texttt{EMERGE-CARRIER-003F},

\operatorname{receipt}(f),

\]

The frontier receipt contains only the pair, microstate source, replicate, feedback cell, capsule, step, current-sequence hash and reference candidate receipts. It contains no score, admission, repair outcome or future state.

The sham label assigned to candidate \(c_i\) is:

\[
b_{r,f}^{sham}(c_i)=b_f(c_{\pi_{r,f}(i)}).
\]

The sham ranking formula is:

\[
R_{t,r}^{sham}(c)
=
R_t^{003C}(c)+0.01b_{r,f}^{sham}(c).

This construction guarantees, at every evaluated frontier:

\[
\operatorname{multiset}(B_f)
=

It therefore preserves exactly:

Only the candidate-to-event assignment changes. Sham labels are explicit control labels; they are never asserted to be geometric projections and are never used to update EMA, persistence, inventory or observer state.

The fourteen salts are the fixed two-digit strings `01` through `14`. No schedule may be selected or discarded after outcomes are observed.

## 7. Primary estimand

For matched pair \(j\), feedback state \(Z\), and sham schedule \(r\):

\[
\Delta_{j,Z}^{(r)}
=
Y_j(true\ assignment,Z)-Y_j(sham_r\ assignment,Z).

Sham choice is averaged within each matched pair:

\[
\overline{\Delta}_{j,Z}
=
\frac{1}{14}\sum_{r=1}^{14}\Delta_{j,Z}^{(r)}.

The primary estimand is:

\[
\overline{\Delta}_{Z=1}
=
\frac{1}{8}\sum_{j=1}^{8}\overline{\Delta}_{j,Z=1}.

The true native candidate assignment establishes useful repair information only if:

\[
\boxed{\overline{\Delta}_{Z=1}>0}

and the two-sided 95% interval across the eight matched-pair ensemble effects lies entirely above zero.

No individual schedule, capsule, action type or pair may substitute for the complete-ensemble criterion.
